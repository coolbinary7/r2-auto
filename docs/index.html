Auto R2
Code source
Extension Firefox · R2

Le mail de mise en ligne, saisi dans R2.

Tu colles le mail du label (titre, artiste, date, auteurs, mix…), tu vérifies la fiche, et l’extension remplit R2 : release, piste, crédits. Elle s’arrête et te prévient dès qu’un choix ne peut pas être deviné.

Installer dans Firefox

  1. Télécharge le fichier .xpi ci-dessus.
  2. Dans Firefox, ouvre about:debugging#/runtime/this-firefox.
  3. Clique sur « Charger un module complémentaire temporaire… » et choisis le fichier .xpi.
  4. L’icône de l’extension apparaît en haut à droite (ou dans le menu puzzle 🧩).

« Temporaire » : l’extension disparaît à la fermeture de Firefox, il faut la recharger ensuite. Une version signée par Mozilla, installée pour de bon, viendra avec R2 Auto.

Utiliser Auto R2

  1. Clique sur l’icône R2 : le panneau s’ouvre à gauche de Firefox. Colle le mail du label, clique Analyser le mail, puis choisis le WAV pour la durée (lu sur place, rien n’est envoyé). Vérifie la fiche : ce qui est « à confirmer » est en orange.
  2. Dans R2, ouvre le projet du label de l’artiste, puis clique ▶ Lancer tout sur le bandeau Auto R2 (en haut à droite).
  3. L’extension repère toute seule la dernière sortie de l’artiste dans l’arbre (là où il est artiste principal) et enchaîne : copie de la release, titre / UPC / date, retrait de l’ancienne piste et de l’ancienne cover, copie de la piste, ISRC, durée, auteurs, mix/master, cover (3000 px, 300 dpi, RGB, TIFF) sans les anciens contributeurs secondaires.
  4. Dans Identify, c’est toi qui choisis la bonne personne (Select) : l’extension continue toute seule.
  5. À la fin, elle rouvre la release : vérifie (anciens auteurs de la piste copiée notamment) et fais toi-même le Submit Release.

Si un élément n’est pas trouvé, le bandeau te dit quoi faire à la main et reprend dès que l’écran attendu s’affiche. Les boutons écran par écran de la 0.1 restent disponibles. Copier le diagnostic sert à signaler un souci.

Enregistrer une saisie (Recorder)

  1. Dans R2, clique sur l’icône, puis ● Démarrer l’enregistrement.
  2. Crée une sortie complète comme d’habitude : release, piste (Resource), crédits, rattachement, jusqu’au bout.
  3. Quand une nouvelle fenêtre s’ouvre (recherche Identify…), clique 📸 Capturer l’écran actuel.
  4. ■ Arrêter, puis ⬇ Exporter : un fichier r2-enregistrement-….json arrive dans tes Téléchargements.

Le Recorder ne fait que regarder : il ne modifie rien dans R2 et n’envoie rien tant que tu n’exportes pas.
